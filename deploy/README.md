# Deploy Scripts

This directory contains scripts for building and deploying container images to Azure Container Registry.

## Prerequisites

- **Azure CLI**: Install from [Microsoft Docs](https://docs.microsoft.com/cli/azure/install-azure-cli)
- **uv**: Python package manager (install via `pip install uv` or from [astral.sh](https://astral.sh/uv))
- **Azure Authentication**: Run `az login` and set correct subscription with `az account set --subscription <SUBSCRIPTION_ID>`
- **Terraform Outputs**: Run `terraform apply` first to generate the `.env` file with infrastructure details

## Configuration

The `.env` file is automatically generated by Terraform's `config_files` module and contains:

```env
ACR_NAME=<acr-name>              # Azure Container Registry name
RESOURCE_GROUP=<rg-name>         # Resource group containing infrastructure
BASE_NAME=<base-name>            # Base name for resource naming
```

**Note**: Do not edit `.env` manually - it's managed by Terraform and will be overwritten on next `terraform apply`.

## Build and Deploy MCP Server

The `build_and_push_mcp.py` script performs a complete build and deployment:

1. **Validates prerequisites**: Checks Azure CLI installation and authentication
2. **Triggers remote build**: Uses `az acr build` to build the Docker image in Azure (no local Docker required)
3. **Updates Container App**: Automatically updates the MCP Container App with the new image

### Usage

```bash
# Navigate to deploy directory
cd deploy

# Run the build and deploy script
uv run python build_and_push_mcp.py
```

### What Happens

The script will:

1. Load configuration from `.env` file
2. Verify you're logged in to Azure
3. Upload build context from `src/tools/products_mcp/` to ACR
4. Build the container image using ACR Build (linux/amd64 platform)
5. Push the image to ACR with tag `products-mcp:latest`
6. Update the MCP Container App (`aca-mcp-daf-{BASE_NAME}`) with the new image
7. Display the new revision name

## Benefits

- **No Local Docker**: Builds happen in Azure, no local Docker daemon required
- **Fast Builds**: Uses Azure infrastructure for quick builds
- **Automatic Push**: Image is automatically pushed to ACR after successful build
- **Automatic Deployment**: Container App is updated immediately after successful build
- **Secure**: Build happens in Azure network
- **Consistent Platform**: Always builds for `linux/amd64` platform

## Troubleshooting

### Error: "ACR_NAME is not set in .env file"

**Solution**: Run `terraform apply` to generate the `.env` file.

### Error: "Not logged in to Azure"

**Solution**: Run `az login` and `az account set --subscription <SUBSCRIPTION_ID>`

### Error: "Failed to update Container App"

**Note**: The image was built successfully and is available in ACR. You can manually update it:
```bash
az containerapp update \
  --name aca-mcp-daf-{BASE_NAME} \
  --resource-group {RG} \
  --image {ACR}.azurecr.io/products-mcp:latest
```
